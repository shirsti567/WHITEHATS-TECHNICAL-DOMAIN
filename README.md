## 3. Cybersecurity news I read recently
- **Incident:** The Snowflake / Ticketmaster Data Breach
- **What happened:** Major cloud data warehousing compromise affected Snowflake customer environments, exposing massive volumes of data for hundreds of organizations, most notably Ticketmaster.Attackers targeted customer database accounts that lacked Multi-Factor Authentication (MFA).Threat actors used stolen or harvested legacy/credential-stuffing pairs rather than breaking into Snowflake's core system architecture.
- **What I learned:** Multi-Factor Authentication (MFA) is non-negotiable for all cloud environments, as hackers easily exploit stolen passwords via credential stuffing rather than software bugs
